## GitHub-এ প্রথমবার তোলার নিয়ম

1. GitHub-এ নতুন একটা Repository খুলুন (যেমন `sera-agro`), Public রাখুন।
2. **Add file > Upload files** চাপুন।
3. এই ফোল্ডারের ভেতরের **সব ফাইল ও ফোল্ডার** (index.html, css, js, images ইত্যাদি) টেনে এনে ছেড়ে দিন। জিপ ফাইলটা নিজে আপলোড করবেন না, আগে Extract করে নিন।
4. নিচে **Commit changes** চাপুন।
5. **Settings > Pages** এ যান। Source হিসেবে **Deploy from a branch** বেছে Branch: `main`, Folder: `/ (root)` দিয়ে Save করুন।
6. এক-দুই মিনিট পর ওপরে ওয়েবসাইটের লিংক দেখা যাবে।
